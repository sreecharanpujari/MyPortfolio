# Sree Charan Pujari — Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Features
- Responsive layout and mobile navigation
- Light/dark theme with saved preference
- Project, skills, education and Google Cloud achievement sections
- Live public GitHub repository list
- Accessibility support, reduced-motion handling and scroll-to-top control
- Search and social-sharing metadata

## Files
- `index.html` — page structure and content
- `style.css` — responsive design and themes
- `script.js` — navigation, theme, GitHub API and interactions
- `favicon.svg` — site icon

## Run locally
Open the folder in VS Code and launch `index.html` with the Live Server extension, or open the file directly in a browser.

## Deploy
The site is published with GitHub Pages from the `main` branch and repository root:
https://sreecharanpujari.github.io/MyPortfolio/
