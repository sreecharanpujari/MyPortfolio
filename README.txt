# Sree Charan Pujari — Portfolio

A responsive, light-theme personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and project details
- `style.css` — responsive layout and visual styling
- `script.js` — mobile navigation and automatic public GitHub repository listing

## Preview locally
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open `index.html` in a browser (or use the Live Server extension).

## Publish with GitHub Pages
1. Open https://github.com/sreecharanpujari/MyPortfolio
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, and `script.js` from this folder.
4. If GitHub asks whether to replace existing files, review the changes and confirm.
5. Click **Commit changes**.
6. Open **Settings → Pages** and confirm the source is `Deploy from a branch`, branch `main`, folder `/ (root)`.
7. Wait for the Pages deployment to finish, then visit:
   https://sreecharanpujari.github.io/MyPortfolio/

## Personalisation notes
- The profile-photo and resume sections are intentionally omitted until those files are ready.
- The Google Cloud badge section uses broad topic categories, not invented individual badge titles.
- The repository section loads public repositories from GitHub's public API. If the API is unavailable, the GitHub profile link remains available.
- CareBridge AI includes an educational-prototype disclaimer.
